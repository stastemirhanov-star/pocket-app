3. Формати здачі

Для цеху

  • PDF — друковані креслення А3 / А2
  • Штамп, масштаби, розміри в мм
  • Окремі карти гнуття для трубогиба

Вихідні файли

  • DWG / DXF — редаговані креслення
  • Сумісність: AutoCAD, BricsCAD, nanoCAD
  • Шари: каркас, обшивка, фланці, розміри
